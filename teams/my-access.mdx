---
title: "My access"
description: "See your permissions and request one you do not have"
icon: "key"
---

**My access** is in the sidebar. There you see, for each team you belong to, which permissions you have and which ones you can request.

For each team you see the name, **Your role**, and a link to **People**.

Below that there are two blocks:

- **Platform access.** Dashboard sections and features available to you on that team.
- **Account permissions.** What you can do on each linked account.

A permission you already have is shown as active. If you are missing one, use **Request this permission from Owners**. When you send it, the notice is **Permission request sent to {team} Owners**. If you already requested it, you see **This permission is already pending approval** and the label changes to **Requested**.

If you do not belong to any team yet, the screen says **No team memberships**.
